# Support

CutSignal is an alpha open-source research/engineering project. There is no paid support, response
time guarantee, medical service, or production uptime commitment.

- Usage and reproducible software problems: use the
  [GitHub issue chooser](https://github.com/limingrui679-design/cutsignal/issues/new/choose) with a
  synthetic minimal example.
- Security or privacy problems: follow [SECURITY.md](SECURITY.md) and use
  [private vulnerability reporting](https://github.com/limingrui679-design/cutsignal/security/advisories/new);
  never disclose exports, credentials, private reports, or exploit details in a public issue.
- Medical, nutrition, or training decisions: consult an appropriately qualified professional. The
  issue tracker cannot assess an individual's health or prescribe targets.

Before filing, run `cutsignal doctor --json`, read `docs/TROUBLESHOOTING.md`, and inspect the exact
error without pasting sensitive data.
