# Security policy

## Current support state

The public source repository is maintained on the `main` development line. No supported binary
release, long-term-support branch, response-time guarantee, or backport policy is currently offered.

## Reporting

Do not open a public issue containing an export, credential, private report, or exploit details.
Use [GitHub private vulnerability reporting](https://github.com/limingrui679-design/cutsignal/security/advisories/new)
for a confidential report. Include the smallest synthetic reproduction, affected version or commit,
impact, and suggested mitigation when known. Do not transmit sensitive records to demonstrate a
problem.

Never attach personal Apple Health, training, food, or medical records. Replace them with the
smallest synthetic fixture that reproduces the problem.

## Scope

Especially relevant reports include unsafe archive handling, credential leakage, report inclusion
of raw identifiers, path traversal, dependency compromise, and a privacy scanner bypass. Statistical
disagreement without a security impact belongs in an ordinary issue and should include assumptions.
